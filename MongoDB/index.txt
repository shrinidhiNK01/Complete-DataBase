Database:- An organised collection of data ,controlled by softwaress


MongoDB = NoSql database 
Store data in Flexible json formate 
Handle large amount of Unstructured data
Stores data in Collections and Documents
A document is a set of key value pair 
Collection is group of Documents
Collection:- Table
Document:- Json Record within a Collection(Row)
Field:- Column 

Reason by you should Nosql Database:
. Scalability and Flexibility
. Variety of Data Types
. Real-time Data Ingestion
. Distributed Computing
. Schema-less Design

NoSQL:-
==================
1)scale Horizontally  by adding More servers  , distributing the loads across Multiple Nodes
2)Schema Less Design , easy storage , rapid changing data without needing to alter the schema 
3)High speed read and write operations
4)Best for realtime data Processing
5)Good for joins, ACID Transactions
6)Effieciently Handle Unstructured data 

SQL:- 
====================
1)scale Vertically by adding more resources to Single Server , which has limits and can be costly 
Horizontal scaling(Shreading) is more complex and less effiecient
2)It is Predefined schema 
3)Good For structured data

3)Update:- updateOne(),updateMany()
db.cars.updateOne(
    {model:"Nexon"},
    {$set:{color:"Red"}}
)
db.cars.updateOne(
    {model:"Nexon"},    
    {$unset:{airbags:2}}
)

//Push and pull used for the arrays
//if we did not give the array name, it will create a new array

db.cars.updateOne(
    {model:"Nexon"},  //filter to find the specfic document
    {$push:{features:"Heated Seats"}}  //update
)
db.cars.updateOne(
    {model:"Nexon"},  //filter to find the specfic document
    {$push:{features:{$each:["Sunroof","Heated Seats","Premium Audio"]}}}  //update many items 
)
db.cars.updateOne(
    {model:"Nexon"},  //filter to find the specfic document
    {$pull:{features:{$each:["Sunroof","Heated Seats","Premium Audio"]}}}  //remove many items 
)

db.cars.updateMany(
    {maker:"Tata"},
    {$set:{color:"Red"}}
)

db.cars.updateMany(
    {maker:"Tata"},
    {$set:{price:{$multiply:[1.2,price]}}}
)

Operators:- 
========================
$lt   ==  <
$lte  ==  <=
$gt   ==  >
$gte  ==  >=
$eq   ==  =
$ne   ==  !=
$in   ==  in 
$nin  ==  not in 
$and  ==  and 
$or   ==  or 
$not  ==  not 
$nor  ==  nor

1)Find the cars with engine more than 1400cc
==========================================
db.cars.find({"engine.displacement":{$gt:1400}})

2)Find the cars with engine less than 1400cc
==========================================
db.cars.find({"engine.displacement":{$lt:1400}})

3)Find the cars with engine equal to 1400cc
==========================================
db.cars.find({"engine.displacement":{$eq:1400}})

4)Find the cars with engine not equal to 1400cc
==========================================
db.cars.find({"engine.displacement":{$ne:1400}})

5)Find the cars with engine less than or equal to 1400cc
==========================================
db.cars.find({"engine.displacement":{$lte:1400}})

6)Find the cars with engine more than or equal to 1400cc
==========================================
db.cars.find({"engine.displacement":{$gte:1400}})

7)Find the cars with engine in the array [1400,1500,1600]
==========================================
db.cars.find({"engine.displacement":{$in:[1400,1500,1600]}})

8)Find the cars with engine not in the array [1400,1500,1600]
==========================================
db.cars.find({"engine.displacement":{$nin:[1400,1500,1600]}})

9)Find the cars with engine less than 1400cc or more than 1600cc
==========================================
db.cars.find({$or:[{"engine.displacement":{$lt:1400}},{"engine.displacement":{$gt:1600}}]})

10)Find the cars with engine less than 1400cc and more than 1600cc
==========================================
db.cars.find({$and:[{"engine.displacement":{$lt:1400}},{"engine.displacement":{$gt:1600}}]})

11)Find the cars with engine having 1498 and 2179cc
==========================================
db.cars.find({"engine.displacement":{$in:[1498,2179]}})
db.cars.find({"engine.displacement":{$nin:[1498,2179]}})

12)Find the cars with engine having 1498 or 2179cc
==========================================
db.cars.find({"engine.displacement":{$or:[1498,2179]}})

Elementary Operators:=
========================
$set:=ADD element or UPDATE element
$unset:=REMOVE element
$exists:=Check if element exists
$type :=Check element type

db.cars.find({maker:{$exists:true}})
db.cars.find({maker:{$exists:false}})
db.cars.find({maker:{$type:"string"}})
db.cars.find({maker:{$type:"null"}})
